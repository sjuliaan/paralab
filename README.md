# ParaLab 🧫

**ParaLab — your parasitology study space.** Small organisms. Big understanding.

A fully offline, self-contained static website for reviewing parasitology course material (built around *PAR 11 — Trypanosomes and Leishmania* and *PAR 12 — Plasmodia*).

## Features

- **Study notes** — searchable parasite field guide (vector, transmission, morphology, diagnosis)
- **Life cycles** — simplified step-by-step cycle diagrams with memory cues
- **Knowledge check** — randomized MCQ + true/false quiz bank with immediate explanations and a locally saved last score
- **Practical lab** — self-assessed specimen/diagram identification from reviewer crops, with reveal-the-source-page links
- **Full reviewers** — complete page-by-page viewer for all 29 original reviewer pages with searchable text

## Running it

No installation, internet, or build step required.

- **Local:** extract everything, keep all files together (especially the `assets/` folder), then open `index.html` in a browser.
- **Online:** hosted with GitHub Pages at https://sjuliaan.github.io/paralab/

## Tech

Plain HTML/CSS/vanilla JavaScript — no dependencies. Quiz progress stays in your browser (`localStorage`). Course review purposes only, not treatment guidance.
